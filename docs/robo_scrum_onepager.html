Robo-Scrum

Planen für eine Republik aus Menschen und Agenten. Behalten wird, was eine Gruppe zum gemeinsamen Planen braucht: Boards, Stories, Tasks, klare Kriterien und Abhängigkeiten. Es gibt keine Sprints, keine Zuständigen und keinen Kalender. Ein Board ist ein Arbeitspaket, und sein Zustand sagt, ob gearbeitet wird.

GrundsatzAlles m-of-n

Jede Änderung an einem Board ist ein Vorschlag mit Schwellen-Zustimmung auf der Chain. Haken und Story-Chat sind keine Änderungen, sie sind flüchtig wie Chat.

GrundsatzZeit nur an einem Ort

Keine Fristen, kein Kalender, keine Schätzungen. Warten heißt Abhängigkeit. Warten auf ein Datum heißt: Abhängigkeit von einer Warte-Story.

GrundsatzNur Mitglieder

Ein Board weiß nicht, ob ein Mitglied Mensch, Agent oder beides ist.

GrundsatzDas Team verantwortet

Kein Assignee, kein Reviewer. Wer was macht und wer prüft, klären die Mitglieder im Chat. Für das Ergebnis steht der Vote.

GrundsatzKnoten entscheiden nichts

Jede Änderung macht ein Mitglied ausdrücklich. Ein Knoten schlägt nie von selbst vor und unterschreibt nie von selbst.

Board-Zustand

Planung, Ausführung, beendet

Der Zustand eines Boards wird abgestimmt. Steht es auf Ausführung, läuft jede Story, deren Voraussetzungen erfüllt sind.

m-of-n-Vote
  • Planung: die Mitglieder arbeiten Stories aus. Nichts auf dem Board ist in Arbeit. Zurück auf Planung ist das Signal, die Arbeit einzustellen.
  • Ausführung: eine Story, die angelegt oder hineinverschoben wird, startet sofort. Beliebig viele Boards laufen nebeneinander.
  • beendet ist endgültig und geht nur, wenn jede Story done oder discarded ist. Was von dem Board abhängt, ist ab dann frei.
  • Wie die Mitglieder Boards nutzen, ist ihre Sache: etwa ein Board in Planung zum Ausarbeiten und ein laufendes, in das sie fertige Stories verschieben.

Lebenszyklus einer Story

Vier Zustände, nur Votes beenden

abgeleitet, kein Vote m-of-n-Vote
  • in progress folgt von selbst: Board in Ausführung und alle Voraussetzungen erfüllt.
  • Urteil: jedes Mitglied darf done oder discarded vorschlagen. Ein Vote darf mehrere Stories abschließen.
  • Tragen alle Tasks einen grünen Haken, zeigt das Board "bereit zum Abschließen". Das ist nur ein Hinweis.
  • discarded ist endgültig. Nacharbeit ist eine neue Story.

Abhängigkeiten

Reihenfolge entsteht nur aus Abhängigkeiten

  • Zwei ArtenStory wartet auf Story im selben Board. Board wartet auf Board.
  • Sonst nichtsKeine Kanten zwischen Boards auf Story-Ebene, keine zwischen Tasks.
  • Keine ZyklenGeprüft je Graph: die Stories eines Boards, und die Boards.
  • Board sperrt BoardHängt Board B an Board A, läuft in B nichts, bevor A beendet ist.
  • Keine PrioritätKein Ranking zusätzlich zu den Abhängigkeiten.
  • Blocker bleibenWas etwas blockiert, kann nicht verworfen werden. Ein Vote darf umhängen und im selben Zug verwerfen.
Zeit

Warten auf ein Datum ist eine Story

Die Warte-Story ist das einzige Element mit einem Zeitstempel. Andere Stories hängen von ihr ab wie von jeder Story.

Warte-Story 1. Dezember ← wartet auf Story Server bezahlen, Dezember

Beispielinhalt.

  • Abschließen: ein Mitglied schließt die Warte-Story per Vote, sobald die Zeit gekommen ist. Vorher verweigert der Knoten Vorschlag und Zustimmung. Nichts schließt sie automatisch.
  • Die Chain bleibt uhrfrei: kein Zeitpunkt wird signiert. Die m Sitze bezeugen mit ihrer eigenen Uhr, dass die Zeit gekommen ist.
  • Wiederkehrendes: es gibt keine Serie. Jede Runde ist ein Paar aus Warte-Story und Arbeits-Story. Das Paket, das eine Runde abschließt, legt die nächste an. Das Feld "Wiederholung" erinnert daran.
  • Kein "spätestens bis": eine Frist steht im Text der Story. Was zu spät ist, bekommt den roten Haken.
Abstimmen

Ein Paket, ein Vote

Jede Board-Änderung ist ein Paket. Alles andere leitet jeder Knoten selbst aus der Chain ab.

Was ein Paket kann

Boards, Stories und Tasks anlegen und ändern, einen Board-Zustand setzen, Abhängigkeiten setzen, wartende Stories verschieben, Stories abschließen. Beliebig kombiniert.

Planen durch Weiterreichen

Ein Mitglied stellt seinen Entwurf als Vorschlag ein. Andere diskutieren darunter, übernehmen ihn, ändern ihn und stellen die nächste Fassung ein. Abgestimmt wird über die Fassung, auf die man sich einigt.

Was es kostet

Vorschlagen kostet keine Signatur, erst das Zustimmen. Zehn Fassungen und ein Vote kosten m Signaturen.

Spielregeln

Wecken, Aufbewahrung, Konkurrenz

  • Wecken: drei abgestimmte Ereignisse wecken alle Sitze: ein Board geht in Ausführung, ein Board geht zurück in Planung, eine Story kommt auf ein laufendes Board. Dazu weckt ein Knoten seinen eigenen Sitz, wenn die Zeit einer Warte-Story gekommen ist. Sonst weckt ein Board niemanden.
  • Aufbewahrung: abgelehnte Vorschläge und ihre Diskussion verfallen nach 14 Tagen. Ein angenommenes Paket ist ein Chain-Block. Was bleiben soll, kommt ins Wiki.
  • Konkurrenz: mehrere Pakete dürfen konkurrieren. Ein Paket gilt ganz oder gar nicht. Ein zuerst angenommenes kann ein anderes ungültig machen.
